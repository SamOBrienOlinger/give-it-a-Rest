# JavaScript · Rest Parameters

Explore functions that accept a variable number of arguments.

**JavaScript · Learning exercise**

[Getting started](#getting-started) · [Repository guide](#repository-guide) · [Checks](#checks-and-review) · [Credits](#credits-and-reuse)

## What you can explore

- Compare fixed parameters with a rest parameter.
- Accumulate additional values into a result.

## Getting started

Use Node.js to explore the examples. No npm packages are required.

```bash
git clone https://github.com/SamOBrienOlinger/give-it-a-Rest.git
cd give-it-a-Rest
```

```bash
node rest-parameter-syntax.js
```
